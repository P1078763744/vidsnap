How URL Trim Works
Enter the video URL + start/end times in seconds
The server downloads only that segment using yt-dlp
ffmpeg trims it precisely and sends back the clip
Example: start=60, end=90 → downloads seconds 60–90
Trim Tips
Fast mode uses stream copy — instant, no quality loss, ±1 keyframe accuracy
Precise mode re-encodes — frame-accurate, takes a few seconds longer
All processing happens on your local server — no cloud, no size limits
⚙️
Start the Backend First
VidSnap needs its Python backend running to download & trim videos. Open a terminal and run:
cd /path/to/vidsnap pip install flask flask-cors yt-dlp python server.py
Make sure ffmpeg is also installed and in your PATH.
Then refresh this page.
